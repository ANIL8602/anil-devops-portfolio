04 / How I work

Small steps. Working system.

I like to understand what each resource does and verify the connection before moving to the next layer.

STEP 01

Define the foundation

Model Azure resources in Terraform: resource groups, virtual networks, subnets, NSGs, public IPs, and VMs.

STEP 02

Connect the services

Check DNS, routes, firewall rules, and database access. Trace the request from the app to the data store.

STEP 03

Automate and observe

Practice pipeline validation and deployment gates, then use monitoring and alerts to understand system health.
