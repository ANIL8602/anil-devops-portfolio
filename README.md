# Anil Kumar Kushwaha — DevOps Portfolio

A responsive portfolio site featuring the Axion telemetry project and hands-on work with Azure, Terraform, FastAPI, React, PostgreSQL, and Nginx.

## Run locally

Open `index.html` in a web browser. The page is self-contained and does not require a build step.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` and this README.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to provide the website URL.

The Axion project content describes a personal learning project. Update the page as your project changes.
